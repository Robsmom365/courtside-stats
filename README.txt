COURTSIDE BASKETBALL STATS — VERSION 1

1. On your laptop, unzip the folder and double-click index.html to test the tracker in your browser.
2. For iPhone installation and offline operation, upload all four files (index.html, manifest.webmanifest, sw.js, icon.svg) together to an HTTPS static website. Keep them in the same directory.
3. Open the HTTPS site in Safari on your iPhone, tap Share > Add to Home Screen.
4. Launch from the Home Screen while online once, then turn on Airplane Mode and verify that the tracker opens, records entries, and retains them after closing/reopening.
5. In Setup, download a FULL backup regularly. Local browser data can be lost if Safari storage is cleared or the app is removed. Data is NOT automatically synced between laptop and phone. Use JSON backup and restore to transfer game history.

NOTES
- Choose a player, shot type, then MADE/MISSED. The chosen player and shot type stay selected.
- Rebound records one rebound. Undo removes the most recent entry.
- The opponent score is entered manually.
- Starting a new game retains previous games in history.
- Roster edits change the currently open game and future games; other saved games retain their roster.
- CSV exports include quarter and full-game player statistics.
- Use the iPhone as the main scorekeeping device. Browser storage is local to each device.
